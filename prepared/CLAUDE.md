# LEXUS IS 200 — ONE SCROLL SITE

## Концепция
Один бесконечный скролл. Никаких отдельных секций.
Фон — canvas анимация из кадров на весь экран всегда.
Текст появляется и исчезает в нужные моменты скролла.
Как Apple iPhone страницы.

## Стек
- HTML5 Canvas (кадровая анимация)
- GSAP + ScrollTrigger (управление скроллом и текстом)
- Lenis (плавный скролл)
- Все библиотеки через CDN

## Структура output
index.html
css/style.css
js/main.js
assets/fonts/
canvas/frames/

## Принцип работы
1. Canvas занимает весь экран (position: fixed, 100vw x 100vh)
2. Кадры меняются синхронно со скроллом
3. Текстовые блоки position: fixed поверх canvas
4. Появляются/исчезают через GSAP в нужные моменты прогресса
5. Общая высота страницы: 8000px (даёт длину скролла)

## Правила кода
