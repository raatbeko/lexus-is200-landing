# СЕКЦИЯ: Color Picker

ЦЕЛЬ: Пользователь видит машину в разных цветах.
При клике на цвет — машина меняется с крутой анимацией.
Референс: Nike sneaker color picker (плавающий товар + выбор варианта сбоку)

ВЁРСТКА:
- Тёмный фон #0A0A0A, на всю ширину
- Слева: заголовок + цена + описание + кнопка "Связаться"
- По центру: большое фото машины (PNG без фона), парящее над фоном
- Справа: вертикальный список цветовых кружков с названиями
- Снизу по центру: навигация PREV / NEXT для переключения

ЦВЕТА И ФАЙЛЫ:

АНИМАЦИЯ (это самое важное):
При смене цвета:

1. Старая машина: улетает вправо (X: 0 → 150px) + fade out + лёгкий scale(0.85)
   Duration: 0.4s, ease: power2.in

2. Новая машина: влетает слева (X: -150px → 0) + fade in + scale(0.85 → 1)
   Duration: 0.5s, ease: power3.out

3. Фоновое свечение под машиной (radial gradient) меняет цвет под цвет машины
   Например для синей машины: rgba(26,58,110,0.3) в центре → прозрачный

4. Заголовок и цена: меняются с лёгким fade (opacity 0 → 1, Y: 10px → 0)
   Duration: 0.3s с задержкой 0.2s после смены машины

5. Активный кружок: анимированный border вращается (CSS border-radius + rotation)
   Или: пульсирующее красное кольцо вокруг активного цвета

PREV/NEXT:
- Кнопки внизу по центру как на референсе
- При клике — та же анимация смены машины
- Счётчик: "01 / 04", "02 / 04" и т.д.

ТЕХНИЧЕСКИЕ ДЕТАЛИ:
- Использовать GSAP для всех анимаций смены
- Машина висит с лёгким float эффектом (CSS animation, Y: 0 → -12px → 0, 3s infinite)
- При hover на машину: лёгкий scale(1.03) + тень усиливается
- Кружки справа: при hover — scale(1.1), при active — красная обводка #E03030
