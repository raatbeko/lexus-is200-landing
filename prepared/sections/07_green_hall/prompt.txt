АНИМАЦИЯ ПЕРЕКЛЮЧЕНИЯ
═══════════════════════════════

JavaScript логика:
1. Клик на таб → убрать активный класс со всех табов
2. Добавить активный класс на кликнутый
3. Скрыть текущую карточку: opacity 0 → display none (150ms)
4. Показать нужную карточку: display flex → opacity 0 → opacity 1 (300ms)
5. scrollIntoView({ behavior: 'smooth', block: 'start' })

Transition карточки:
- opacity: 0 → 1, duration: 0.4s, ease: power2.out
- translateX: 30px → 0 (карточка приходит справа при появлении)
