# ТЕКСТОВЫЕ OVERLAY

Все тексты position: fixed поверх canvas.
Появляются и исчезают через GSAP в зависимости от прогресса скролла.

ПРОГРЕСС 0% → 15% (начало):
  Текст: "LEXUS IS 200"
  Подтекст: "2004 — 2006"
  Позиция: центр экрана
  Анимация: fade in при 0%, fade out при 15%

ПРОГРЕСС 15% → 30%:
  Текст: "3.0L INLINE-6"
  Подтекст: "200 л.с. Легендарная надёжность"
  Позиция: левый нижний угол
  Анимация: slide from left + fade in, fade out к 30%

ПРОГРЕСС 30% → 45%:
  Текст: "ЗАДНИЙ ПРИВОД"
  Подтекст: "RWD — классика для тех кто понимает"
  Позиция: правый нижний угол
  Анимация: slide from right + fade in, fade out к 45%

ПРОГРЕСС 45% → 60%:
  Текст: "ЯПОНСКАЯ ТОЧНОСТЬ"
  Подтекст: "Каждая деталь создана с целью"
  Позиция: центр экрана
  Анимация: fade in + scale 0.9 → 1, fade out к 60%

ПРОГРЕСС 60% → 75%:
  Текст: "8.3 СЕК"
  Подтекст: "Разгон 0 — 100 км/ч"
  Позиция: центр, очень крупно (Bebas Neue, 20vw)
  Анимация: countUp от 0 до 8.3 при появлении

ПРОГРЕСС 75% → 90%:
  Текст: "РОЖДЁН ДЛЯ ДОРОГИ"
  Подтекст: нет — только крупный заголовок
  Позиция: центр
  Анимация: каждое слово появляется с stagger 0.2s

ПРОГРЕСС 90% → 100%:
  Canvas затемняется (overlay opacity 0 → 0.85)
  Появляется форма связи поверх тёмного фона
  Заголовок: "ГОТОВ СТАТЬ ТВОИМ?"
  Поля: Имя + Телефон
  Кнопка: "ОТПРАВИТЬ ЗАЯВКУ"
