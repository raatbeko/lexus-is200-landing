# ИДЕЯ
Редакционный сайт-гид о походах в горы.
Стиль как у премиальных outdoor журналов.
Цель: вдохновить читателя и дать полезную информацию.

# НАСТРОЕНИЕ
Тёмное, атмосферное, природное.
Много воздуха. Крупная типографика. Минимум декора.

# НЕ ДЕЛАТЬ
- Яркие цвета кроме акцента
- Много иконок
- Тесная вёрстка
- Bootstrap стиль

# ШРИФТЫ
Заголовки: Playfair Display — элегантный serif
Основной текст: Inter — чистый, читаемый, weight 300/400
Номера секций (01, 02, 03): Bebas Neue — крупно, серый цвет

# АНИМАЦИИ
- Все элементы появляются снизу при скролле (Y: 40px → 0, opacity 0 → 1)
- Фото появляются чуть медленнее чем текст
- Stagger между элементами: 0.15s
- scrub: false, duration: 0.8s, ease: power2.out
