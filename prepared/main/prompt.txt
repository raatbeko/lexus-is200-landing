# ИДЕЯ ПРОЕКТА
Лендинг для продажи Lexus IS 200 2004-2006 года.
Чёрный автомобиль, спортивный седан, культовая модель.
Сайт должен передавать: мощь, агрессию, премиальность.
Покупатель должен захотеть написать и купить эту машину.

# РЕФЕРЕНСЫ
Стиль как у: chery-ev.com, lamborghini.com, darkстиль автомобильных сайтов

# НАСТРОЕНИЕ
Тёмное, агрессивное, кинематографичное.
Много воздуха между элементами. Крупная типографика.
Машина — главный герой каждой секции.

# НЕ ДЕЛАТЬ
- Светлый фон
- Bootstrap-стиль
- Мелкий текст везде
- Много иконок подряд
- Дешёвый вид кнопок

# ШРИФТЫ
Заголовки: Bebas Neue (Google Fonts)
  — использовать для всех h1, h2, h3, названий секций, цифр характеристик
  — всегда капслок, letter-spacing: 0.02–0.06em

Основной текст: Space Grotesk (Google Fonts)
  — weight 300 для описаний и мелкого текста
  — weight 400 для обычного текста
  — weight 500 для подписей, лейблов, навигации
  — НЕ использовать weight 600 и выше — тяжело смотрится рядом с Bebas

Подключение:
@import url('https://fonts.googleapis.com/css2?family=Bebas+Neue&family=Space+Grotesk:wght@300;400;500&display=swap');

# АНИМАЦИИ (общий характер)
- Плавные но уверенные. Не быстрые, не медленные.
- Заголовки появляются снизу вверх (Y: 60px → 0)
- Машина на hero появляется справа (X: 100px → 0)
- Секции проявляются при скролле через ScrollTrigger
- Кнопки: hover эффект с красной подсветкой
